# Резервна копія анімацій (Animations Backup)

Цей документ містить опис усіх анімацій та переходів, які були використані на сайті до їх тимчасового вимкнення. Щоб повернути анімації, необхідно відновити ці класи та властивості у відповідних компонентах.

## 1. Framer Motion (Поява елементів під час скролу)

Майже у кожному компоненті (Hero, Gifts, Outcomes, Form, About, Testimonials) використовувалась бібліотека `framer-motion`. 
Елементи обгортались у теги `motion.div`, `motion.h1`, `motion.img` тощо.

Стандартні властивості анімації для поступової появи знизу:
```tsx
import { motion } from 'framer-motion';

// Приклад використання на елементі:
<motion.div
  initial={{ opacity: 0, y: 20 }}
  whileInView={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.7, delay: 0.1 }} // delay збільшувався для кожного наступного елемента (0.1, 0.2, 0.3...)
>
  Контент
</motion.div>
```

## 2. CSS Анімації (Tailwind)

### Банер з цитатою (LifestyleQuoteBannerSection)
Для фонового зображення у банері з цитатою використовувалась повільна пульсація.
- Віддалений клас: `animate-pulse-slow`
- Налаштування у `tailwind.config.js`:
  ```javascript
  animation: {
    'pulse-slow': 'pulse 4s cubic-bezier(0.4, 0, 0.6, 1) infinite',
  }
  ```

### Зображення (Ефект наведення)
Усі фотографії на сайті мали ефект переходу від чорно-білого (grayscale) до кольорового при наведенні миші.
- Віддалені класи на `<img>`: `hover:grayscale-0 transition-all duration-700` (або `duration-500` у картках)
- Залишений клас: `grayscale` (щоб фото залишались в естетиці сайту)

### Кнопки
Кнопки мали плавні переходи кольору при наведенні.
- Класи: `transition-all`
- (Ці класи не вилучались, оскільки вони є стандартним UX для кнопок, але якщо потрібно повернути повну статику, їх також можна видалити).
